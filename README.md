⚔️ BLADE // Terminal Simulator

A visual cyberpunk terminal traffic simulator built in Python using `rich`. It simulates high-speed log output and thread telemetry without generating real network traffic.

---

## 📋 Prerequisites

Before running the script, ensure you have Python installed:
* **Python 3.8 or higher** (Check version with `python --version`)
* **Git** (Check with `git --version`)

---

## 🚀 How to Install and Run

### Step 1: Clone the Repository
Open your terminal or PowerShell and run:
```bash
git clone [https://github.com/YOUR-USERNAME/blade-simulator.git](https://github.com/YOUR-USERNAME/blade-simulator.git)
cd blade-simulator
Step 2: Install Dependencies
Install the required rich library:

Bash
pip install -r requirements.txt
Step 3: Launch the Simulator
Run the main script: python main.py

Bash
python main.py
